## 本轮实测结论（都已写进 skill 与 .workbuddy-ai 记录）

1. **可点区带**（两张卡一致、边界很利）：锚点 −110..−30 → 只读 tooltip；+0..+80 → 确定购买；
   ±100 以外 → 无。**上一轮"点商人立绘关 tooltip"的结论建立在错的分层上。**
2. **金色六边形图标（统帅经验，3116 px、宽高比 1.21）会被当价格按钮**（真按钮 276×71、宽高比 3.89）。
   后果是探测脚本误判"有浮层"→关了个不存在的框→按返回键退出商店。
3. **第二次确认按钮靠"找数字"找不到** → 合法购买报 `CONFIRM_BUTTON_NOT_FOUND` 且不花钱。
4. **`taps_refused=0`** 证明"点了没反应"是**客户端忽略**，不是宿主拒绝；
   对策是覆盖式阶梯 + 把判定改成不花 OCR 的 OpenCV。
5. 卡列表价格会读错（r1c2 读成 `150`，实际 `53💎`）—— 无害，因为判定用浮层实时价。
