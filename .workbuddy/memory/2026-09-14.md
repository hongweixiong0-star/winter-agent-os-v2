## 本轮真机测量结论（资源搜索面板）

- 页签带 = 7 个页签固定顺序：**野兽 / 冰原巨兽 / 大型锯木厂 / 生肉(MEAT) / 木材(WOOD) / 煤矿(COAL) / 铁矿(IRON)**
- 实测：**间距 pitch = 157px，选中格宽 = 145px**，选中态由白色 L 角标（两条近白竖线，间距恒 144-145px）标记。
- **页签带的滚动偏移会变化**（客户端会把当前选中页签重新居中）。
  实测两种偏移：`0`（生肉在最左）与 `+400px`（野兽在最左）。
  → 旧的固定中心表 `{MEAT:0.25, WOOD:0.4722, COAL:0.6944, IRON:0.9167}` **只对 offset=0 成立**。
- 因此 SELECT_RESOURCE 的正确做法是：**白色角标锚点 → 相对布局(pitch) → 格内模板定身份 → 推算任意页签的点击坐标**。
