## 第五轮（活体验收 + 一次真实回归的发现与回滚）

### 已取得的三条活体结论

   → 结论：**迁取帧，识别逐语义按证据迁**。

3. **生产 episode 出现真实调用链**（`learning/episodes.jsonl`）：

   ```
   skill=OPEN_INTEL result=SUCCESS

   action_backend=MAA  executor_backend=HYBRID  verifier_ok=true
   ```
   MAP → INTEL，MAA 取帧 + MAA 点击（51.06 ms）+ V2 识别 + V2 Verifier PASS。

### 一次真实回归（最重要的一条教训）

`OPEN_INTEL` 的 MAA 识别节点是在**只有 1 张正样本**的语料上提升的，第一次真机运行就回归：
MAA 找对了位置（box 与 manifest ROI 完全一致 623,813,86,96），但相关性只有 **0.448**，
低于默认阈值 0.7 → 动作被拒绝、运行停止（旧路径是 94% 成功）。
根因：**这个按钮的蓝色填充是动画的**，旧语义为此带了放宽的容差；哈希距离的容差
不能搬到模板匹配阈值上。

处置：**把识别轴回滚为 LEGACY**（skill 变成 HYBRID，保留 94% 识别率 + 36× 取帧），
节点移入 `not_migrated` 并写下实测分数；同时给 `tools/maa_migrate.py` 加了**提升闸门**：
正/负样本各 <3 时输出 `PROMOTION BLOCKED` 并置 `corpus_sufficient=false`。
一帧语料无法暴露动画——这条闸门本来就能拦住这次事故。
