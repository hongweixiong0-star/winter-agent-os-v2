## 两条必须记住的边界

1. **不要在 HUD 上找名字。** 城市视图与世界地图的顶部都只有头像画像 / 战力 / 体力 /
   统帅N / 日期，**没有任何名字**（三张帧均已核实）。战力每小时在动、统帅是共有的称号，
   都不能当键。
2. **这个面板里有 `设置` 页签**，而 `config.risk.block_account_or_role_delete` 保护的正是
   那条路径。因此：只允许**读**这一页，**永不点击面板内任何控件**。识别步骤只做
   「点头像 → 取帧 → 读 → Back」。
