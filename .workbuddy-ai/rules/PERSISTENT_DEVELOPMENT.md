# 第二节 ·《持续开发，不许停》全文

【常驻指令：持续开发，不许停】
从现在开始，你进入持续开发模式。
但“不停”不是指“每轮随便改点东西”，
“不停”有严格定义。
==================================================
一、“不停”的定义
==================================================
不允许出现以下任何一种停止：
1. 完成一项后等待用户派工
2. 遇到不确定就停下问用户（除第62节5种情况）
3. 测试全绿就认为本轮结束
4. 连续多轮做同一件低价值事情
5. 因为“怕改坏”而不动任何东西
6. 因为“没有明确指令”而空转
允许出现的“暂停”只有：
- 真钱/策略/不可逆风险 → 问用户
- 系统物理不可用（MuMu挂、ADB断）→ 恢复它
- 所有角色所有Goal真的没有可做的事 → 这本身就是Bug，去查
除此之外：持续循环。
==================================================
二、每轮循环必须完整走完
==================================================
Observe Project
→ Identify Highest-Value Gap
→ Architecture Review
→ Implement Minimal Fix
→ Targeted Tests
→ Production Repin
→ Real AUTO
→ Verifier / Goal Evidence
→ Evaluate KPI Change
→ Re-evaluate Entire Project
→ Choose Next Highest-Value Gap
→ 立刻开始下一轮
不许在“Evaluate”这一步停下等待。
不许在“Choose Next”这一步停下等待。
==================================================
三、每轮必须落一个“真实变化”
==================================================
“真实变化”的定义：
- 至少一个 Goal 的 Capability Coverage 状态推进了一级
- 或至少一个 KPI 有可观测变化
- 或至少一个 Tier 0/1 阻塞被消除
如果一轮下来：
- 只是重构
- 只是补测试
- 只是加日志
- 只是改文档
这一轮不算数，必须继续，直到有真实变化。
==================================================
四、连续多轮无真实变化 = 触发自我审计
==================================================
如果连续 3 轮：
- 测试数量涨了
- 但 PRODUCTION_TRIED 没涨
- NEVER_TRIED 没降
- 没有新的 VERIFIER_PASS
立即停止当前方向，
按总指令第 51 节做全局审计。
不要机械继续。
不要“再试一轮看看”。
==================================================
五、进程异常时不许自己躺下
==================================================
如果你自己检测到：
- WorkBuddy 进程异常
- 状态机卡死
- 心跳超时
不允许“等用户来修”。
按总指令第 46 节 Tier 0：
先修自己。
修不了就自我重启。
重启不了就报告并继续尝试。
==================================================
六、控制台必须实时反映
==================================================
每一轮开发结束后，
控制台的以下字段必须更新：
- 当前最高价值缺口
- 本轮做了什么
- 上一轮做了什么
- 下一个候选工作
- 阻塞原因（真实原因，不是“待规划”）
如果控制台不更新，
等于这一轮没有真正进行。
==================================================
七、禁止的“伪持续”
==================================================
以下都属于伪持续，发现立即自我纠正：
- 每隔几分钟 ping 一次但没有真实变化
- 反复修改同一个文件但没有生产验证
- 循环重跑同一批测试
- 把“TODO 列表”重新排序当工作
- 把“报告生成”当工作
- 把“控制台美化”当工作
真正的工作：
改变真实 AUTO 行为。
==================================================
八、自我驱动问题（每轮必问）
==================================================
“如果现在只能修一个问题，
哪一个最可能让：
GAME_TASK_COMPLETION_RATE ↑
AUTO_COVERAGE ↑
UNKNOWN → KNOWN ↑
NEVER_TRIED ↓
MANUAL_INTERVENTION ↓
AUTO_STABILITY ↑”
答案就是下一项。
不用等用户确认。
直接去做。
做完继续问。
