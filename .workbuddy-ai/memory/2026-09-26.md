- 脚本静态审计干净：无网络外发 / 无 subprocess / 无凭证访问；唯一外部依赖是 `maa_mcp` 包（`from maa_mcp.adb/vision/pipeline_tools import ...`）。
- **依赖裁决：不装 maa_mcp。** V2 已有等价能力（`winter_agent_v2/ocr.py` 的 `OCRService`+`RapidOCRBackend`、`device.py` 的 `ADBDevice.screenshot`），装了就是第二套设备链，违反操作者铁律。

**方法论嫁接（核心决策）**
- 该技能三步法：连接设备 → OCR 取 box+score → 扩大 ROI（默认 expand=20）→ 合并进 MaaFramework pipeline JSON。
- **V2 没有 pipeline/ 目录、没有 interface.json**（全仓库 0 命中）。落点改为 V2 感知候选三件套：`knowledge/perception/candidates/<id>/{element.png,context.png,metadata.yaml}` + `INDEX.json` 追加。
- Action 种类约束：V2 的 `Action.kind` 只有 4 种合法值（TAP_SEMANTIC/PRESS_BACK/SWIPE/OBSERVE），生成器不得发明新 kind。

**真机实战（2026-09-26 01:17，设备 127.0.0.1:7555）**

- 红点按 `entry_badges.red_pixel_rule`（r≥150, r-g≥50, r-b≥50, 连通域≥40px）测得 blob=(335,884,7,16)=112px。
